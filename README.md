# 🏋️‍♀️ calculadora_imc

Uma calculadora simples de Índice de Massa Corporal (IMC) desenvolvida com JavaScript. 📊

## 📌 Visão Geral

Este projeto consiste em uma calculadora de Índice de Massa Corporal (IMC) interativa, construída utilizando HTML para a estrutura, CSS para o estilo e JavaScript para a lógica de cálculo e manipulação da interface. Ela permite que os usuários insiram seu peso e altura para obter o seu IMC e uma classificação correspondente.

## ✨ Funcionalidades Principais

* **🔢 Entrada de Dados:** Permite que os usuários insiram seu peso (em quilogramas) e altura (em metros).
* **🧮 Cálculo do IMC:** Realiza o cálculo do IMC utilizando a fórmula padrão: $\text{IMC} = \frac{\text{peso (kg)}}{(\text{altura (m)})^2}$.
* **📊 Classificação do IMC:** Exibe a classificação do IMC com base nos resultados (por exemplo, abaixo do peso, peso normal, sobrepeso, obesidade).
* **🎨 Interface Amigável:** Uma interface de usuário intuitiva e responsiva construída com HTML e estilizada com CSS.
* **🔄 Feedback Instantâneo:** Os resultados e a classificação são exibidos imediatamente após o cálculo.

## 💻 Como Usar

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/amarildorpg/calculadora_imc.git](https://github.com/amarildorpg/calculadora_imc.git)
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd calculadora_imc
    ```
3.  **🌐 Abrir no navegador:**
    * Abra o arquivo `index.html` no seu navegador web.

4.  **📝 Utilizando a calculadora:**
    * Insira seu peso no campo correspondente (em kg).
    * Insira sua altura no campo correspondente (em metros).
    * Clique no botão de "Calcular" ou similar.
    * O resultado do seu IMC e a respectiva classificação serão exibidos na página.
